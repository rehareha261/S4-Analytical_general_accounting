# S4 ERP Project

## Introduction
Le projet S4 ERP est une application web développée avec Django, destinée à la gestion des ressources d'une entreprise (ERP). Elle vise à faciliter le suivi et l'analyse financière, en fournissant des outils pour la comptabilité et la gestion des comptes.

## Structure du Projet
Le projet est structuré autour de plusieurs modules et utilise une architecture basée sur Django:
- **comptable** : Contient les fonctionnalités liées à la comptabilité, incluant l'analyse des comptes et la génération de rapports.
- **S4_ERP** : Le noyau du projet qui gère le routage et la configuration de l'application.

## Fonctionnalités Principales
- Gestion des comptes
- Calculs financiers via des tags templated Django
- Interface d'administration pour gérer les données

## Prérequis
- Python 3.x
- Django 4.x
- Autres dépendances listées dans `requirements.txt`
