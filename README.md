# Projet Gemini

## Description
Ce projet contient plusieurs plugins et fonctionnalités développés pour offrir une variété de services. Voici un aperçu des principaux fichiers et fonctionnalités identifiés dans le projet :

## Fonctionnalités du projet

- **Gruntfile.js** : Utilisé pour configurer des tâches automatisées pour le développement, comme la minification de fichiers JavaScript.
- **bs-custom-file-input** : Une bibliothèque JavaScript permettant de styliser les champs de fichier des formulaires de manière personnalisée.
- **fullcalendar** : Une bibliothèque JavaScript pour créer des calendriers interactifs et riches en fonctionnalités sur le web.
- **codemirror/mode/dockerfile** : Un mode pour l'éditeur CodeMirror permettant de visualiser et d'éditer des Dockerfiles.
