# Projet Comptable

Bienvenue dans le projet Comptable. Ce projet est conçu pour gérer les opérations comptables et fournir une interface utilisateur conviviale grâce aux plugins Summernote.

## Architecture

Le projet utilise Summernote comme éditeur WYSIWYG pour une expérience utilisateur simplifiée lors de la saisie de texte enrichi. Les fichiers JavaScript pour Summernote se trouvent dans le répertoire `comptable/static/plugins/summernote/`.

## Prérequis

- Python 3.x
- pip
