# Projet Comptable

## Description
Ce projet contient des scripts et des dépendances pour la gestion comptable. Le projet inclut l'utilisation de plusieurs plugins et outils pour faciliter différentes tâches associées. 

## Fonctionnalités

### Plugins JavaScript

1. **bs-custom-file-input.js**
   - Plugin pour personnaliser l'affichage des entrées de fichiers dans le navigateur. Permet d'afficher un nom de fichier personnalisé après la sélection dans l'entrée de fichier.

2. **Gruntfile.js**
   - Utilisé pour l'automatisation de tâches telles que la minification de fichiers JavaScript via Grunt, un outil de build JavaScript.

3. **dockerfile.js** (CodeMirror Mode)
   - Implémentation d'un mode pour le Dockerfile dans CodeMirror, offrant une syntaxe surlignée pour les fichiers de Docker.

4. **main(.min).js** (FullCalendar)
   - Utilisé pour la gestion de calendriers interactifs sur un site web, probablement pour l'organisation d'événements ou de tâches.

### Dépendances

- `requirements.txt`
  - Contient une liste des dépendances Python requises pour exécuter le projet, qui devront être installées dans l'environnement Python pour assurer le fonctionnement correct des scripts associés.

## Comment démarrer
Pour démarrer avec le projet, assurez-vous d'installer toutes les dépendances nécessaires listées dans `requirements.txt` en utilisant `pip install -r requirements.txt`. Ensuite, configurez les plugins JavaScript en incluant leurs fichiers dans votre projet web selon vos besoins.
